# To-Do List Application

This is a simple console-based To-Do List application implemented in Java. The program allows users to manage a list of tasks by adding new items, removing existing ones, and viewing the entire list.

## Features

- **Add item**: Add a new task to your to-do list.
- **Remove item**: Remove a specific task from your list based on its number.
- **Display list**: Shows the current list of tasks with numbering.
- **Exit**: Exit the application.

## How to Use

1. **Run the Application**: Once the application starts, the current to-do list will be displayed (empty initially).
2. **Choose an Action**: You will be prompted to choose an option from the menu:
   - Press `1` to add an item to your to-do list.
   - Press `2` to remove an item by its number.
   - Press `3` to exit the application.
3. **Add an Item**: When you choose `1`, you will be prompted to enter the description of the task you want to add.
4. **Remove an Item**: If you choose `2`, enter the number corresponding to the task you wish to remove. If the number is valid, the task will be deleted.
5. **Exit the Program**: Choose `3` to exit the program. The app will thank you and close.

## Requirements

- **Java**: Make sure you have the Java Development Kit (JDK) installed on your machine.
- **Compiler**: Use any Java IDE or the command line to compile and run the `todo.java` file.

## Compilation and Execution

1. **Compile the code**:
   ```
   javac todo.java
   ```
2. **Run the program**:
   ```
   java todo
   ```
